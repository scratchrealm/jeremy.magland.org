---
title: "AreWeHuman for Web Apps and Presentations"
---

I have always enjoyed making interactive web applications and presentations for communicating science. I learn best when I can explore datasets and results by adjusting parameters, slicing through images, or scrolling synchronized time views. Over the years I developed coding skills that have allowed me to efficiently create these interactive pages. It was a lot of work, but I felt that it has paid off, and I enjoyed doing it.

Now we have entered the age of AI-assisted coding, and things have changed quite a bit. On the one hand, it is a lot easier to new create content now. At first this was exciting. I used code completion tools and found that I could create more, with reduced carpal tunnel symptoms! Then powerful coding agents emerged, and things improved even further.

But recently, these models have become so good that a natural language prompt can generate an entire complex web application in a single shot. Granted, it still takes effort to get things to my liking. But I expect that models will continue to improve, and the skills I had honed are becoming less necessary. So a lot of the joy is gone. Furthermore, I feel like people are now inundated with impressive-looking AI-generated tools, and so providing cool interactive widgets doesn't have the same zing as it used to. It's becoming more difficult to differentiate between tools that were planned and developed with a lot of care and things that were vibe coded.

I've decided that I do want to continue creating these tools. As I said, it's the way I naturally learn and I feel like it's the best method for communicate science in many cases. So I am thinking outside the box to try to make this work! You'll find my solution below.

First some context. I think that human-generated content will always have value compared with AI-generated content, no matter how good AI gets. Certainly for some tasks AI is simply superior. For example, writing the detailed HTML/CSS code for proper page layout across devices -- that's something I never want to struggle with again. But for other things, imperfect human-generated writing is full of life compared with the hollowness of the perfectly crafted pros (it makes me think of emptiness and death).

Even in the case where the output of AI cannot reliably be distinguished from human output (think future art, music), here are some reasons that human output is worth pursuing. First for the author, it takes effort to create something, and that process is worthwhile and invaluable for learning and growth. Second, for the reader/user, knowing something was human generated means that it should be accessible by a human, and that a person can vouch for and take responsibility for the product.
