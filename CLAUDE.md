# jeremy.magland.org

## Authorship rule

All prose on this site is written by Jeremy. Do not write, draft, outline in prose, suggest wording for, or edit sentences in any post, summary, or transcript, unless Jeremy explicitly asks for that specific text.

- Video transcripts: mechanical tidying only (drop filler and false starts, fix transcription errors, punctuation, paragraphs, section headings, links). No rewording, no added sentences.
- Allowed: suggesting topics, gathering material, building web apps and interactive visualizations that posts embed, publishing mechanics (video upload, post files, links between posts), formatting (links, code blocks for commands, headings).
- `drafts/ai-posts/` is AI-written and must never be published or used as text.
